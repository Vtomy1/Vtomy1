Image → 4-bit EGA

Convert an image to the classic 16-color EGA palette with optional Floyd–Steinberg dithering. Export packed 4-bit pixels or QBASIC DATA statements.

Export

Binary format: row-major pixels, two pixels per byte, first pixel in the high nibble and second in the low nibble. If the pixel count is odd, the final low nibble is zero.

QBASIC loader / saver example

Set W and H to the dimensions used for conversion. This example reads/writes the packed .EGA bytes and unpacks each palette index into PIX() (values 0–15).
